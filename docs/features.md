## Features of lifepim-ai-core

This document lists the features of the package.

### Data & Retrieval

- Metadata file listing
- Metadata extraction to DB
- Chunking & re-chunking
- Chunk statistics (size, overlap, counts, coverage)
- Document-to-chunk traceability


### Retrieval & Inference

- Embedding model switching
- LLM / engine switching (Ollama, local models, etc.)
- Search + retrieval pipeline
- Top-K control & scoring visibility
- Context injection (RAG plumbing)


### Prompting & Behaviour

- Custom prompts
- Personality switching
- Prompt templates

### Dev / Power-user Utilities

- Local-only operation
- Plain config files
- Hackable internals
- No telemetry, no licensing hooks
